# Skybound Rush 🚀

An original 2D arcade flight game prototype built with **Unity 6 LTS**.

Guide your celestial flying creature through an endless corridor of floating crystal spires and shifting cloudscapes!

---

## 🎮 Gameplay & Controls

- **Space** or **Left Mouse Click**: Flap / Fly upward
- **Space**, **R**, or **Left Mouse Click** (on Game Over): Instant Restart
- Dodge the glowing crystal spires
- Pass through the gaps to score points and set new records

---

## 🛠️ Project Structure

- Assets/Scripts/: C# gameplay scripts (PlayerController, ObstacleSpawner, Obstacle, GameManager, ScoreManager, UIManager, ParallaxScroller).
- Assets/Scenes/: Main gameplay scene (MainGame.unity).
- Assets/Prefabs/: Prefabricated game objects including ObstaclePair.prefab.
- Assets/Sprites/: Generated game textures (player sprite, spires, clouds, particles).

---

## 💻 Opening in Unity

1. Open **Unity Hub**.
2. Click **Add** -> **Add project from disk**.
3. Select the SkyboundRush folder.
4. Recommended Editor Version: **Unity 6 (6000.0.84f1)** or later.
5. Open Assets/Scenes/MainGame.unity and press **Play**!
